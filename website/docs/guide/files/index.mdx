# xcdl files

**xcdl** stores its specific metadata definitions
in JSON files. There are no mandatory names, any name can be used;
the defaults are:

- [xcdl-package.json](/docs/guide/files/xcdl-package.json/)
- [xcdl-project.json](/docs/guide/files/xcdl-project.json/)
