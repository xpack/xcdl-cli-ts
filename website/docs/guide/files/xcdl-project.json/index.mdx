# xcdl-project.json

## Overview

The `xcdl-project.json` file is used to store the xCDL configurations.

Component authors can use any name and place the file in any location, but the
default is to use `xcdl-project.json` and place the file where the
source tree is, for example the project top folder for user
applications or the `tests` folder.
