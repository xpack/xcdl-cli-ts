## Purpose

Define an array of test objects.

## Syntax

```json
{
  "cdlTests": [
    {
      "id": "<artefact name>",
      "display": "<short name>",
      "description": "<long text>",

      ... test members ...
    },
    ...
  ]
}
```

## Example

```json
{
  "cdlTests": [
    {
      "id": "sample.runner",
      "display": "Sample Test Runner",
      "description": "A simple test to exercise an object linked into multiple lists",
      "dependencies": [
        "tests.sample.binary"
      ]
    },
    {
      "id": "unit.runner",
      "display": "Unit Test Runner",
      "description": "A comprehensive test for all lists",
      "dependencies": [
        "tests.unit.binary"
      ]
    },
    {
      "id": "unit.runnerCoverage",
      "display": "Unit Test Runner with Coverage",
      "description": "A comprehensive test for all lists with coverage",
      "dependencies": [
        "tests.unit.runner"
      ]
    }
  ]
}
```
