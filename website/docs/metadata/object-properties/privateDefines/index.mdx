# `privateDefines` property

:::note

Work in progress. 

:::

## Purpose

Specify compiler preprocessor macros passed on the compiler command line
when compiling the source files of the current component.

## Syntax

```json {2}
{
 "cdlOptions | cdlComponents": [
    {
      "id": "...",
      ...
      "privateDefines": [ 
        "<name>[=<value>]",
        ... 
      ],
      ...
    }
  ]
}

```

The value of the `privateDefines` property is an array of
names, possibly with values.

## Default value

If missing, the current object will not contribute any preprocessor macros to
the build.

## Description

Generally, preprocessor macros are defined at the top level and apply to all
sources that enter the build.

In some cases, it might be necessary to define preprocessor macros for each
component.
