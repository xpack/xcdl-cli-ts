# xcdl configure

:::note

Work in progress.

:::

## Synopsis

```sh
xcdl configure [options...] --configuration-file <JSON file> --cdl-configuration <name>
```

Aliases:

- none

## Description

Add or edit an xCDL configuration in the JSON file.

If a `cdtConfigurations` object with that name does not exist, it is created.

The configuration process writes the configuration to the JSON file, 
such that `xcdl setup` will have all the data to create the build tree.

---

Inspiration:

```
ecosconfig ...
```

- https://ecos.sourceware.org/docs-latest/user-guide/manual-configuration.html

However, it must be noted that `ecosconfig` has different goals and 
the functionality has little resemblance with **xcdl**.
