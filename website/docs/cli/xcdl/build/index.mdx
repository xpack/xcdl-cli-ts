# xcdl build

:::note

Work in progress.

:::

## Synopsis

```sh
xcdl build [options...] [--target <name>] ...TBD
```

Aliases:

- none

## Description

Runs the builder in the current folder, which is expected to be a build tree.

- `--target` use a custom target.

A target named `clean` can be used to clean the build folder.
